# Lightelligence

> Lightelligence (Shanghai Xizhi Technology Co., Ltd. / 曦智科技, founded 2017) builds optoelectronic
> hybrid computing hardware — photonic accelerators and optical interconnect fabric for AI and
> high-performance computing. It publishes no public web API, no OpenAPI/AsyncAPI/GraphQL contract,
> no MCP server and no A2A agent card. Its software surface is device-side: ONNX/OpenCL/PyTorch/TVM
> support plus a Python SDK that ran models on the optical processing unit. That SDK and its
> documentation have both been withdrawn from public distribution.

## APIs

- No public API. Lightelligence's products are physical: the PACE 2 optoelectronic accelerated
  computing card (PCIe Gen4 x16, 128x128 optical matrix multiplier), the Gazelle optical computing
  evaluation board, the Photowave CXL optical interconnect and the Lightsphere X distributed optical
  circuit switch. There is no hosted endpoint to call.

## Specifications

- None published. No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Protobuf service definition, WSDL,
  JSON Schema or Postman collection was found on any Lightelligence host or in the company's GitHub
  organization.

## Packages

- lightelligence-sdk (PyPI, Python) — WITHDRAWN. The device-side "lt_sdk" that compiled and ran
  models on the optical processing unit. https://pypi.org/project/lightelligence-sdk/ no longer
  exists (HTTP 404 on the PyPI simple index); the last version referenced by the company's own
  example repository is 0.1.15.
- model-vis 0.0.22 (PyPI, Python, published 2020-08-17) — an ML model graph visualization tool from
  the Lightelligence GitHub organization. Not an API client. Abandoned.

## Source code

- GitHub organization: https://github.com/Lightelligence — 15 public repositories, chip design and
  verification tooling rather than API clients: rules_verilog (Bazel build rules for Verilog),
  yis (SystemVerilog RTL/DV/SystemRDL generation from a YAML interface spec), lintworks,
  meticulous_rtl, draconian_uvm, uvmf, sv_proto, rules_systemc, runmod, claude_kit.
- SDK examples: https://github.com/Lightelligence/SDKExamples — still online, still instructs
  installing the withdrawn lightelligence-sdk package.
